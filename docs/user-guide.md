# CFIS v1.0 用户使用手册

本版本面向本地运行和初版演示。金额通过十进制字符串传输，最多4位小数；不同币种分别统计，不自动汇兑。

## 启动与登录

Windows安装.NET 10 SDK、Node.js/npm、Git及Docker Desktop，打开Docker Linux引擎。在项目根目录执行：

```powershell
./scripts/start.ps1
./scripts/status.ps1
```

浏览器访问 http://127.0.0.1:5173 。首次使用注册账户，密码至少12位且包含大小写、数字和符号，然后登录。初次启动需要联网恢复依赖和构建镜像。已有配置、密码及数据库卷不会自动覆盖。

停止使用 `./scripts/stop.ps1`。脚本只停止自己创建并核对过路径的前端进程，以及本项目Compose服务，不删除数据卷。此前独立启动的前端仍由原入口停止。端口5432、5080、5173需可用；启动失败按提示查看日志。

登录凭据仅保存在内存中。刷新后重新登录，地址中的企业编号在确认成员身份后恢复，不会绕过权限。退出使该用户旧会话失效。

## 界面语言

首次打开默认为中文。登录页或页头点击 English 切换英文，点击 中文 切回。语言选择保存在当前浏览器，刷新、退出再登录、切换企业后仍沿用；同一浏览器的其他标签页同步变化。不同浏览器或设备不自动同步。

导航、表单、表格、状态、图表、安全操作与提示随选择切换。切换不会提交或清空当前表单，也不改变金额、币种、日期或账务规则。企业/账户/分类名称、业务说明、附件名称等业务原文保持不变。Excel/PDF沿用现有服务端输出格式。

## 首次使用与演示

首页的首次使用指南可以收起和重新打开。点击“生成或打开演示账套”会建立当前用户独立拥有的合成企业，不写入原有企业。

演示包含银行/现金、分类、客户供应商、部分结算的应收应付、预算预警、普通分摊、内部转账、会计映射、已过账和冲销凭证、待处理草稿及图片附件。重复点击沿用相同账套及请求编号，不重复入账，不重置用户之后的操作。没有删除或重置真实企业的功能。

演示账套初始资金合计14500.0000，应收剩余1500.0000，应付剩余1500.0000；会计收入7500.0000、费用3000.0000，原始手工调整与冲销相抵。草稿不影响账务，结账前需要处理。

## 工作空间与企业

创建企业后点击企业行选中，或使用页头“切换企业”。导航地址保留企业编号；切换企业会重新加载模块数据。首页优先显示本月收支、截至今天资金和待处理凭证数量。

左侧导航进入独立业务页面；首页快捷入口使用相同页面。手机点击左上角展开导航，选择页面后自动收起，也可以点击遮罩或按 Esc 关闭。长页面顶部提供分区导航，表格在窄屏内可左右滑动。成员添加、角色调整、邀请和密码操作统一在“企业设置”。

Owner和Accountant可以办理财务；Owner和Admin可以管理成员和查看审计；Viewer只读。Admin没有财务写权限。邀请代码有效48小时，由管理员通过可信渠道交付；已有用户须先登录本人账户，新用户可在接受邀请时设置密码。

成员降权或移除在之后请求中立即生效。Owner不能通过成员管理接口被降权或移除。邮件服务未配置时，密码找回入口显示不可用；本人修改密码及管理员邀请仍可按界面办理。

## 资金管理

建立银行或现金账户，选择币种；建立收入和支出分类。账户与分类支持改名、停用和归档，不提供删除。账户币种创建后固定，归档要求余额为零。

期初只能在账户尚未发生业务时登记，须填写来源说明。普通收入、支出和同币种转账立即改变已登记余额。内部转账同时办理转出和转入，不能透支。业务日期与系统记录时间分别保存，未来日期登记也立即改变已登记余额，页面会确认提示。

交易不可直接修改。需要更正时先撤销，再按新业务内容登记；“撤销并准备更正”保留关联供检查后提交。原记录、撤销记录和审计均保留。

### 分类分摊

普通收入、支出可勾选“按多个分类分摊”。仍填写一笔交易总额，添加2–100个不重复、有效、同方向分类及各自金额。明细必须为正数，精确合计等于总额。界面实时显示分摊合计；切换为转账或期初时自动退出分摊。

一次分摊只增减一次资金。分类统计和预算按各明细金额计算，生成会计凭证时逐分类映射。撤销反转完整明细。转账、期初、应收应付结算不支持分摊。

旧单分类交易继续有效，无需改写历史或已过账凭证。Excel交易导出增加“分类分摊”工作表；该表是总额组成，不能与交易总额相加。

## 往来与预算

客户/供应商可以共同使用一个往来方。应收应付录入金额、币种、分类、发生及到期日期后，可多次部分结算；付款或收款不得超过剩余金额。结算生成真实资金流水，不另行重复登记收支。

错误结算先撤销资金流水；单据净结算为零后才能取消。已有确认凭证时还需要冲销确认；确认已冲销的单据不能继续新增结算，应取消重建。

预算先保存草稿，再启用。调整采用新版本，保留旧版本；同分类、同币种、重叠期间的启用规则由系统检查。超支提供预警，不阻止付款。草稿和关闭预算可查看执行，但不混入当前启用版本汇总。

## 会计管理

建立不重叠的开放期间、明细科目及业务映射。已有资金与单据采用完整历史接入：从最早业务日期补齐期间和来源凭证，已有期初流水只导入一次，不能额外再建同金额期初。

来源先生成草稿，核对后过账。批量生成和过账每批最多50项，每项独立提交，返回逐项结果；处理错误原因后可重试成功项，不重复入账。

已过账表头和分录不能修改或删除，只能追加冲销。资金来源凭证须先撤销对应资金流水，再导入反向流水。手工凭证不会自动收付款。草稿可以修改或删除，操作保留审计。

通过来源编号查找凭证，从凭证分录打开科目明细，再从明细返回凭证。试算检查借贷相等，资金对账检查资金流水与映射总账余额。差异只报告，不自动改账。

结账先运行预检查，打开阻塞明细处理草稿、漏记来源及未映射账户，并解决对账差异。正式提交会重新检查。关闭后不提供重新开放；本版本不自动年结。

## 附件

可以在资金流水、应收应付、已过账凭证详情操作，也可从“业务附件”输入业务类型和编号。支持PDF、PNG、JPEG，每个最多5MB，每项业务最多100个。

系统校验大小、扩展名和文件头，下载按附件返回，不以内联页面执行。文件校验不代表杀毒扫描。附件与业务必须属于同一企业；下载需要当前有效成员权限，上传需要财务写权限。

附件只追加，不删除或覆盖。误传文件在后续新文件的名称或业务说明中标明更正，历史凭据继续保留。此规则也适用于已过账凭证。

首版采用PostgreSQL二进制存储，文件、关联和审计在同一事务保存。数据库备份即包含附件字节，无需额外文件目录；恢复工具重新计算SHA256验证内容。大规模附件存储不属于首版容量承诺。

## 报表和导出

选择币种、业务日期、可选账户及记录截止时间后查询。页面、Excel及PDF使用相同筛选口径。导出以最近一次成功查询的条件为准；新查询失败时会清除旧结果和导出入口，请修改条件重新查询。资金期初＋期间期初登记＋净收入－净支出＋转入－转出＝期末。

分类收支包含分摊和冲销。企业内部转账在整体资金中抵消；应收应付账龄为企业口径，选择单账户时不展示。

现金收支与会计收入费用口径不同：尚未收款的确认收入可以进入会计试算，但不会增加现金。报表不作为税务申报报表。

## 备份、恢复和维护

```powershell
./scripts/backup.ps1
./scripts/verify-restore.ps1 -Backup backups/实际备份文件.dump
```

备份包含数据库、附件、身份保护密钥及配置；配置含密码，所有备份均属于敏感文件，应加密保管。恢复验证使用随机临时库，不覆盖主库。完整快照不含备份之后写入。

开发验证见 `scripts/validate.ps1`；升级和恢复详见运维手册。日志位于docs下的被忽略日志或output目录。向他人报告问题时提供错误追踪号，勿发送密码、令牌、配置或数据库备份。

## 首版明确不支持

跨币种汇兑、税务、自动年结、折旧、坏账自动处理、多级审批、交易分摊到多张往来单、计划自动付款及附件删除。公网运营验收不属于本次交付。
