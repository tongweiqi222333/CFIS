# CFIS v1.0 功能与验收矩阵

状态：v1.0.0初版验收通过。基线为phase-6-baseline，最终证据见v1-acceptance.md。

|工作包|当前状态|首版验收|
|企业、身份、角色、邀请|已完成并验收|回归身份及企业隔离|
|账户、分类、交易、转账、冲销|已完成并验收|回归余额与审计原子性|
|往来、应收应付、预算|已完成并验收|分次结算、撤销、预算版本闭环|
|报表、Excel、PDF|已完成并验收|与业务及分摊统计一致|
|会计、期间、凭证、对账|已完成并验收|分摊凭证及历史兼容回归|
|附件|已完成并验收|企业隔离、大小/类型限制、下载、审计及备份恢复|
|交易分摊|已完成并验收|普通收入支出精确合计、一次资金变化、分类预算会计冲销一致|
|导航与共享状态|已完成并验收|独立路由、直达、刷新、企业切换|

|用户手册及当前功能清单|已完成并验收|逐模块说明、已知限制、历史文档入口|
|最终验收及发布|已完成并验收|构建、集成、浏览器、升级、备份恢复、CI和v1.0.0标签|

附件与分摊必须完成真实后端及迁移，不使用模拟接口。新功能不得改写历史已过账凭证。不纳入自动年结、汇兑、税务、多级审批或公网运营。

附件采用数据库字节存储，替代单独文件目录，以保证文件、业务及审计原子性；备份包含实际文件内容并校验SHA256。凭证附件只关联已过账记录。
