## 统一交互规则

- 深色侧栏、浅色内容区域、统一主题色、间距、卡片、表格、输入框与反馈样式。
- 页头保留企业切换；地址中的企业编号随业务导航保留。切换页面回到顶部，切换企业重建对应业务面板。
- 手机导航点击页面后收起，包括点击当前页；支持遮罩和 Esc 关闭。窄屏表格在自身区域横向滚动，并显示滑动提示。
- 空企业引导回工作空间，财务只读角色显示说明。权限判断继续由后端执行。
- 收入/支出切换时清除不匹配分类；转账候选账户仅显示同币种有效账户。切换转账或期初时清除不适用的分摊状态。
- 金额预览使用 BigInt 的万分之一整数单位；格式化保留原始十进制字符串。图表数值仅用于绘图，提示和明细保留精确值。
- 业务操作防重复点击；错误反馈保留服务端追踪号，不为本地校验生成虚假追踪号。
- 提供跳到主要内容、键盘焦点样式、表单可见标签、导航语义和加载状态。

## 验证方法与结果

执行：

```powershell
npm.cmd run build --prefix frontend
./scripts/test-browser.ps1
./scripts/start.ps1 -SkipBuild
```

- TypeScript 检查与 Vite 生产构建通过。
- 浏览器回归 6/6 通过（最终运行 36.3 秒），全部使用隔离 PostgreSQL 数据库和真实 API：注册登录与企业成员、资金转账及撤销更正、往来结算与预算及 Excel/PDF、会计过账冲销及封账、企业邀请、分摊与附件及刷新直达、逐页响应式检查。上述业务组合包含在 6 个测试中。
- 页面检查覆盖 1440px 桌面、390px 手机、登录及 9 个业务/帮助页面；验证整页无横向溢出、企业切换后不残留原企业账户、空企业引导、手机导航关闭、交易分摊状态切换、报表校验失败清除旧结果。
- 共生成 58 张截图，覆盖主要页面和长页面各分区，已复核布局。测试检查未发现页面运行异常。
- 本地启动通过，预览地址：http://127.0.0.1:5173/ 。

原始日志：`docs/ui-build.log`、`docs/ui-browser.log`、`docs/ui-start.log`。截图：`frontend/test-results/ui-*.png`。这些生成文件不纳入 Git；重新运行浏览器测试可以复现。测试库在执行结束后删除。
