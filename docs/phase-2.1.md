# Phase 2.1 设计与验收

## 数据与权限变更

新增FinanceIntegrity迁移：账户/分类Status、交易BusinessDate、ReversalOfId、ReversalReason，企业TimeZone；撤销关联含企业ID的复合外键和唯一索引。旧账户分类回填Active，企业回填Asia/Shanghai；旧流水日期由CreatedAt转换至Asia/Shanghai后取日期，不改原记账时间。创建企业可传IANA TimeZone，默认Asia/Shanghai，当前不提供时区修改以避免历史日期语义变化。

FinancePermissions显式定义Read、Write、Audit。Owner/Accountant可写，Owner/Admin可读审计；所有已知角色可读财务；未知角色默认拒绝。企业成员管理仍由Owner/Admin执行，不隐含资金写权限。

cfis为本地迁移管理员；cfis_app为非超级用户，无建库/建角色权限，仅对现有业务表授权，禁止更新/删除/截断transactions和audit_logs、禁止写迁移历史、禁止删除账户和分类。每次迁移后重新授权。应用本身仍逐请求检查企业隔离；这不是数据库RLS，数据库管理员仍有维护权限。

## 撤销与更正

POST /api/v1/organizations/{org}/transactions/{id}/reverse：

    {"requestId":"非空UUID","reason":"必填原因，最多500字","businessDate":"2026-10-30"}

原交易保持不变，反向流水链接原交易。收入/期初反向支出，支出反向收入，转账交换两端。一次原交易只能撤销一次；撤销流水不能再撤销。相同请求原样重试返回200，不同请求重复撤销409；金额不足或超上限409。撤销日期不得早于原业务日期。归档账户需先重新启用；停用账户允许撤销，便于纠错。

使用企业ID+原交易ID的事务advisory lock串行化撤销，随后按固定顺序锁资金账户。这样运行角色无需UPDATE原流水权限。原交易+撤销流水有复合外键与唯一索引，避免跨企业/重复撤销。余额、反向流水及审计同事务提交。

界面“撤销并准备更正”先完成撤销，再将原值填入表单供检查修改，手动提交新流水。新流水说明保留原交易ID；当前未提供两次提交整体原子化，也没有单独结构化CorrectionOf字段。

## 资源生命周期与期初

PATCH /accounts/{id}、/categories/{id}，JSON为{"name":"新名称","status":"Active"}，状态支持Active/Inactive/Archived。归档账户余额必须0，可重新启用。新交易必须引用Active资源；资源改名/状态变更记录审计前后值。账户币种和分类类型固定不变，不提供删除接口。

期初通过POST /transactions、kind=Opening登记，categoryId和destinationAccountId为null，description必须说明来源。金额规则与收入相同。仅未发生业务的账户可设置期初；已有期初完全撤销且无其他业务时可重新登记期初。零期初无需登记，负期初不支持。

所有金额字符串，最多15位整数和4位小数；超过精度直接拒绝。前端校验必填和金额，后端与数据库继续做最终约束。

## 日期、查询与核对

BusinessDate是企业日历日期，CreatedAt是不可编辑UTC系统时间。POST不传日期时使用企业时区当天；界面显式传日期。历史补录允许，无会计期间锁定，当前不校验历史每日余额，仅保证当前余额不透支。

账户/分类GET现在返回分页结构{total,items}，page/pageSize默认1/20，上限100。界面选择器使用当前资源页，翻页后可选择其他资源。

流水筛选新增dateFrom/dateTo，按业务日期包含两端；原from/to继续按UTC时间戳筛选。GET /transactions/{id}返回账户名、币种、分类、操作人、转账两端及撤销链接。界面开放账户和业务日期筛选及详情。

GET /finance-settings返回企业时区、当地日期及写权限。
GET /reconciliation以RepeatableRead快照读取账户与分组流水，按“期初+收入-支出+转入-转出（含反向流水）”核对，返回actual/expected/difference字符串。只报告差异，不静默修复余额。

## 注意事项与下一阶段

撤销流水保留原分类但资金方向相反；后续报表应根据ReversalOfId按原业务类型抵减，不能仅按Kind简单解释为新业务收入/支出。更正重录通过说明关联原交易，未单独引入结构化更正字段。

历史补录不重算每日透支与会计期间；账户/分类下拉使用当前分页数据。审计为数据库运行账号只追加保护，不是管理员不可篡改的外部账本。当前无新的生产发布承诺。
