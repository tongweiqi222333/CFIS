# CFIS v1.0.0 初版

CFIS企业财务信息管理系统初版，面向本地运行、学习和业务演示。核心财务业务自主实现，采用Vue 3、TypeScript、ASP.NET Core、Identity、EF Core和PostgreSQL的模块化单体架构。

## 本地启动

安装.NET 10 SDK、Node.js/npm、Git和Docker Desktop，开启Linux引擎，解压源代码后进入根目录：

```powershell
./scripts/start.ps1
```

访问 http://127.0.0.1:5173 ，注册登录后点击“生成或打开演示账套”。首次启动需要联网恢复依赖和镜像。已有数据卷和密码不应删除或覆盖。

### 独立后端构建包

编译包不是安装器。先在PostgreSQL应用迁移并配置cfis_app权限，再在解压后的后端目录设置自己的连接信息，以本地开发演示模式启动：

```powershell
$env:ASPNETCORE_ENVIRONMENT='Development'
$env:ConnectionStrings__Database='Host=127.0.0.1;Database=cfis;Username=cfis_app;Password=你配置的运行密码'
dotnet CFIS.Api.dll --urls http://127.0.0.1:5080
```

该命令仅启动API，前端仍需静态服务器与同源代理；推荐初次使用直接下载源码包运行start.ps1。Production模式还需要持久化保护密钥和PFX证书配置，详见运维手册。

## 升级

从Phase 6基线升级增加4条迁移，总计16条。先执行`backup.ps1`，再执行`start.ps1`；源代码模式会迁移并重新配置运行角色权限。旧单分类交易通过兼容读取模型保持原口径，不改写已过账历史。

附件只追加，凭证附件要求已过账；普通分摊不支持转账、期初或单据结算。不得将同一笔交易总额和分摊明细再次相加。
